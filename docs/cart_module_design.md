# 电商平台购物车模块设计文档

## 1. 模块概述

购物车模块是电商交易链路中的核心模块，用于暂存用户的购买意图，并在用户下单前完成商品聚合、价格计算、营销匹配等操作。

### 设计目标

-   支持加入商品 / 删除商品 / 修改数量
-   支持游客购物车
-   支持登录用户购物车
-   支持跨端同步（PC / H5 / App）
-   支持促销计算
-   支持购物车 → 订单结算
-   支持高并发访问

# 3. 购物车类型设计

## 3.1 游客购物车

未登录用户购物车。

### 存储方式

-   浏览器 localStorage
-   Redis (tempUserId)

### Redis Key

    cart:temp:{tempUserId}

### 过期时间

    7天

## 3.2 登录用户购物车

### 存储结构

-   Redis（高频读写）
-   MySQL（持久化）

### Redis Key

    cart:user:{userId}

## 4.2 MySQL 表设计

表名

    cart_item

表结构

  字段             类型       说明
  ---------------- ---------- ------------
  id               bigint     主键
  user_id          bigint     用户ID
  sku_id           bigint     SKU ID
  spu_id           bigint     SPU ID
  quantity         int        数量
  checked          tinyint    是否选中
  price_snapshot   decimal    加入时价格
  sku_title        varchar    商品标题
  sku_image        varchar    商品图片
  sku_attrs        varchar    SKU规格
  status           tinyint    状态
  create_time      datetime   创建时间
  update_time      datetime   更新时间

唯一索引

    (user_id, sku_id)

# 5. 核心功能设计

## 5.1 加入购物车

接口

    POST /cart/add

请求示例

``` json
{
 "skuId":10001,
 "count":2
}
```

流程

1 查询SKU信息\
2 校验商品是否上架\
3 校验库存\
4 查询购物车是否已有SKU\
5 已存在 → 数量累加\
6 不存在 → 新增购物车项\
7 写入Redis\
8 异步落库

------------------------------------------------------------------------

## 5.2 修改数量

接口

    POST /cart/update

------------------------------------------------------------------------

## 5.3 删除商品

接口

    POST /cart/delete

------------------------------------------------------------------------

## 5.4 勾选商品

接口

## 5.5 查询购物车

接口

    GET /cart/list

查询流程

1 查询Redis购物车\
2 获取所有skuId\
3 批量查询商品信息\
4 批量查询价格\
5 批量查询库存\
6 查询营销活动\
7 聚合返回

# 7. 失效商品处理

  状态      原因
  --------- --------------
  下架      商品下架
  无库存    库存为0
  超限购    超过购买限制
  SKU删除   商品不存在

------------------------------------------------------------------------

# 8. 购物车合并

登录时执行

tempCart + userCart

合并规则

  情况       处理
  ---------- ----------
  SKU相同    数量累加
  SKU不同    直接加入
  超限购     截断
  商品失效   标记

------------------------------------------------------------------------

# 9. 结算流程

    用户勾选商品
          │
    点击结算
          │
    生成结算数据
          │
    重新计算价格
          │
    检查库存
          │
    检查营销
          │
    返回结算页

------------------------------------------------------------------------

# 10. 下单流程

    购物车
      │
      ▼
    结算页
      │
      ▼
    提交订单
      │
    再次校验
      │
    生成订单
      │
    删除购物车商品

------------------------------------------------------------------------

# 11. 一致性策略

原则

购物车允许弱一致\
订单必须强一致

措施

-   Redis写
-   MySQL异步同步
-   下单最终校验

------------------------------------------------------------------------

# 12. 高并发优化

Redis承接高频操作

-   add
-   update
-   delete

批量查询避免 N+1 查询

非核心逻辑通过 MQ 异步处理
